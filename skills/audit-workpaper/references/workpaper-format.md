# 監査調書の標準フォーマット

事務所様式の指定がない場合に使う標準構成。report-writer はこの構成・記載ルールに従って整形する。

## ヘッダー

| 項目                    | 内容                                                                |
| ----------------------- | ------------------------------------------------------------------- |
| 調書名 / 調書番号       | 例: 「売掛金 期末残高の検討」/ 【要確認: 採番ルール】               |
| クライアント名 / 決算期 |                                                                     |
| 作成者 / 作成日         | 作成者とレビュー欄は空欄で残す                                      |
| 対応する監査要点        | 実在性・網羅性・権利と義務・評価・期間帰属・表示 のうち該当するもの |

## 本文構成

### 1. 目的

この調書で何を確かめるか(監査要点との対応)を2〜3文で記載。

### 2. 範囲・重要性

対象科目・期間・重要性の基準値・母集団と抽出方法。

### 3. 入手資料

資料名・作成者(会社/外部)・日付の一覧表。

### 4. 実施した手続と結果

手続ごとに「手続の内容 → 実施結果(数値・突合結果)」を対で記載。表を積極的に使う。
未実施の手続は「未実施(必要資料: 〇〇)」として区別して記載(削除しない)。

### 5. 発見事項

事実と評価を分けて記載。例外事項がない場合も「例外事項は識別されなかった」と明記。

### 6. 結論

目的に対する結論を1段落で。条件付きの場合(未実施手続がある等)はその旨を結論に含める。

### 7. 根拠・出典

引用した会計基準・監査基準(基準名・号数・項番号)、参照した資料への参照番号。

## 記載ルール

- である調。推測語(「〜と思われる」)は評価の記載でのみ使用し、事実の記載では使わない。
- 数値は資料の値をそのまま転記し、単位(千円/百万円)を統一する。
- 引き渡し資料にない情報は【要確認: 〇〇】として残す。
- 脚注・相互参照(「A-1参照」等)は引き渡し資料に指定がある場合のみ付す。
