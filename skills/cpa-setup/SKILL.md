# cpa-toolkit 初期設定

各スキルが毎回質問しなくて済むよう、恒常的な設定を設定ファイルに保存するスキル。

## 設定ファイルの場所(全スキル共通ルール)

`${CLAUDE_PLUGIN_DATA}/config.json`。環境変数 `CLAUDE_PLUGIN_DATA` が未定義の環境(スキルを `~/.claude/` に直接コピーして使う場合など)では `~/.claude/cpa-toolkit-data/config.json` を使う。このフォルダはプラグインの更新で消えない場所であることが重要(スキルフォルダ内には保存しない)。

## 手順

1. 既存の設定ファイルを読み、現在の設定を一覧表示する(初回は「未設定」)。
2. `references/config-spec.md` の項目について、AskUserQuestion で確認する(利用者が変更したい項目だけの指定があればそれのみ)。一度に全項目を聞かず、カテゴリごとに分けて聞く。「スキップ」された項目は保存しない(各スキルが必要時に個別質問する)。
3. 回答を config.json に保存し、保存内容を表示する。
4. 調書様式・レポート様式のファイル(docx/md)が提供された場合は、設定フォルダ内に `templates/` を作ってコピーし、config.json にパスを記録する。

## 各スキルでの使われ方

全スキルは作業開始前にこのファイルを読み、設定済み項目の確認質問を省略する。作業中に恒常的に使えそうな新しい設定が確認できた場合、利用者の同意を得て追記する(勝手に書き換えない)。

## Gotchas(失敗したら追記して育てる)

- config.json をスキルフォルダ内に保存してしまうと、プラグイン更新時に消える。必ず上記の場所に保存する。
- 設定はクライアント横断の「既定値」である。特定クライアント固有の値(その会社の重要性基準値など)を既定として保存しない。クライアント固有設定が必要なら `clients/<名前>.json` として分けて保存する。
