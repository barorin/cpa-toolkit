# 標準テスト一覧(Journal Entry Testing)

data-processor が実行する機械的テストのカタログ。データ項目で実行可能なものを選定して使う。閾値は呼び出し元(メイン)が指定した値を優先する。

## A. 完全性チェック(常に最初に実行)

| #   | チェック           | 内容                                  |
| --- | ------------------ | ------------------------------------- |
| A1  | 貸借一致           | 借方合計=貸方合計(全体および仕訳単位) |
| A2  | 期間網羅性         | 月別件数に欠落・急減がないか          |
| A3  | 形式検証           | 日付・金額の型、欠損値、重複仕訳番号  |
| A4  | 勘定科目マスタ整合 | マスタ外の勘定コードの有無            |

## B. 時期・タイミング系

| #   | テスト               | 標準条件                                              |
| --- | -------------------- | ----------------------------------------------------- |
| B1  | 期末付近仕訳         | 決算日前後5営業日に計上された仕訳(手入力を優先)       |
| B2  | 休日・深夜仕訳       | 土日祝・22時〜5時に入力された仕訳(入力日時がある場合) |
| B3  | 遡及日付仕訳         | 入力日と計上日の乖離が30日超                          |
| B4  | 決算整理仕訳の一覧化 | 決算整理フラグまたは決算日日付の仕訳全件              |

## C. 金額系

| #   | テスト           | 標準条件                                                                              |
| --- | ---------------- | ------------------------------------------------------------------------------------- |
| C1  | 丸い数字         | 下4桁以上が0の一定金額超の仕訳                                                        |
| C2  | 重要性基準値近辺 | 指定した重要性基準値の90〜100%の金額                                                  |
| C3  | 高額仕訳         | 金額上位N件(標準: 50件)                                                               |
| C4  | Benford分析      | 先頭1桁・2桁の出現分布と理論値の乖離(カイ二乗) ※件数が十分(目安1,000件超)な母集団のみ |

## D. 相手勘定・パターン系

| #   | テスト             | 標準条件                                                                                      |
| --- | ------------------ | --------------------------------------------------------------------------------------------- |
| D1  | 通常外の勘定組合せ | 出現頻度が極めて低い借方/貸方の組合せ(例: 売上と現金以外の異例な相手勘定、収益と負債の組合せ) |
| D2  | 収益認識関連       | 売上勘定に対する手入力仕訳の全件(監基報240の収益認識不正リスク推定に対応)                     |
| D3  | 逆仕訳・振替の多用 | 同額逆仕訳のペア、短期間の計上→取消                                                           |
| D4  | 摘要の異常         | 摘要が空欄・「調整」「その他」等の曖昧語のみの仕訳                                            |

## E. 入力者・承認系(項目がある場合)

| #   | テスト       | 標準条件                                     |
| --- | ------------ | -------------------------------------------- |
| E1  | 職務分掌     | 起票者=承認者の仕訳                          |
| E2  | 権限外入力   | 経理部門以外・上級管理者・IT管理者による入力 |
| E3  | 入力者別傾向 | 入力者別の件数・金額分布、特定入力者への集中 |

## 実装メモ(pandas)

- 金額は `Decimal` または整数(円単位)で扱い、浮動小数点の丸め誤差を避ける。
- 日付は `pd.to_datetime` 後に日本の祝日判定が必要なら `jpholiday` を使う(`pip install jpholiday`。未導入時は土日のみで判定し summary.json に注記される)。
- 出力は `output/` 配下にテスト番号付きCSV(例: `output/B1_period_end.csv`)で保存し、抽出0件のテストも「0件」を報告する。
- D3は仕訳単位の(合計金額, 勘定科目集合)が一致するグループを期間幅(最大日付−最小日付)で判定する近似。同一署名の伝票が3件以上長期間に散在すると取りこぼしがあり得る。
- D4の曖昧語は完全一致(および「〜分」)のみ判定する。誤検知回避を優先した仕様で、「調整仕訳」等の複合語は検出されないため、③の評価時に留意する。
