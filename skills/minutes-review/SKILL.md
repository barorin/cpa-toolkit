# 議事録・契約書レビュー

取締役会議事録・重要契約・稟議書等の文書から、会計・監査上の重要事項を抽出し評価するスキル。

## モデル振り分け

| 工程            | 実行者                            | 理由                                 |
| --------------- | --------------------------------- | ------------------------------------ |
| ①範囲確認       | メイン(高推論モデル)              | 軽い判断                             |
| ②文書からの抽出 | **doc-extractor(低コストモデル)** | 大量読解。メインのコンテキストも節約 |
| ③含意の評価     | メイン(高推論モデル)              | 専門的判断                           |
| ④(必要時)文書化 | **report-writer(低コストモデル)** | 整形                                 |

英文文書が含まれる場合は translator(最安モデル)で一次翻訳してから doc-extractor に渡す(または doc-extractor に原文のまま抽出させ、重要箇所のみ翻訳する)。

## 手順

### ① 範囲確認(メイン)

対象文書(種類・期間・件数)と関心事項(監査全般/特定の論点)を確認する。

### ② 抽出(doc-extractor に委譲)

文書ファイルのパスと以下の標準抽出項目を渡す(関心事項に応じて追減):

- 資金関連: 新規借入・社債・保証・担保提供・コミットメントライン
- 投資・組織再編: M&A、子会社設立・清算、固定資産の重要な取得・除売却、減損の兆候となる決定(事業撤退・拠点閉鎖)
- 損益・引当関連: 訴訟・係争、行政処分、重要な契約の締結・変更・解約、リストラ・人員整理、役員報酬・賞与の決定
- ガバナンス: 役員の異動、会計方針・決算に関する報告、内部統制・不正に関する報告、監査人とのコミュニケーション
- 期末日後の事象(後発事象の候補)
- 契約書の場合: 契約当事者・期間・金額・収益/費用認識に影響する条件(検収、返品、値引、ペナルティ、更新・解約条項)

「各項目に文書名・ページ・決議/報告の別を付し、該当なしの文書も一覧に含める」ことを指示する。

### ③ 評価(メインで実施 — 委譲しない)

抽出結果を読み、各事項について会計処理・開示への影響(引当・減損・偶発債務・後発事象・注記)と監査手続への影響(リスク評価の修正、追加手続)を評価する。会計基準への言及は accounting-consult スキルと同じ出典ルールに従う。フォローアップが必要な事項は「事項・影響・推奨手続」の形で整理する。

## 注意

- 議事録の網羅性(開催回数と入手した議事録の突合)の確認を利用者に促す。
- 抽出漏れリスクがあるため、重要な検討(例: 後発事象の最終確認)では原文の直接確認を推奨する旨を成果物に付す。

## 共通運用ルール

- **設定ファイル**: 作業開始前に `${CLAUDE_PLUGIN_DATA}/config.json`(環境変数未定義なら `~/.claude/cpa-toolkit-data/config.json`)を読む。設定済みの項目(適用基準の既定、重要性方針、様式、閾値、想定読者等)は確認質問を省略する。恒常的に使えそうな新しい設定を確認したら、利用者の同意を得て設定ファイルに保存する(初回セットアップは cpa-setup スキル)。
- **委譲の例外**: 対象が小さい場合(目安: データ数百件以下、文書数ページ、単一の軽い論点)は、サブエージェント委譲のオーバーヘッドの方が大きいため、メインで直接実施してよい。ただし品質工程(最終レビュー・引用突合)は省略しない。
- **Gotchas を育てる**: このスキルの利用中に新しい失敗・つまずきがあったら、下の Gotchas に追記する(CLI では直接編集、Cowork ではチャットで改訂を依頼するよう利用者に一言添える)。

## Gotchas(実際に踏んだ罠を追記して育てる)

- 決議事項だけ見て「報告事項」を読み飛ばすと重要情報(業績報告内の減損兆候、係争の経過報告等)を落とす。両方を抽出対象にする。
- スキャンPDFのOCR品質を過信しない。金額・日付は特に誤認識しやすく、重要な数値は原文画像で確認する。
- 議事録本文だけでなく添付資料・別紙に実質的な内容があることが多い。添付の有無と入手状況を必ず報告させる。
- 開催されたはずの回の議事録が入手資料に含まれていない場合がある。開催回数との突合を利用者に促す。
