# 企業調査レポート 設計ガイド(会計監査事前調査型)

**この文書は穴埋めフォームではない。** 重要な論点は会社ごとに違う。固定の章立てを機械的に埋めた報告書は、重要でない論点に紙面を与え、重要な論点を薄める。読者は「この会社で何が一番危ないか」を知りたいのであって、章の網羅を求めていない。

したがって作業は次の順で行う。

1. **不変の骨格**(第1節)を置く ── 会社を問わず必ず必要な5要素
2. **論点を洗い出し、重要度で順位づけ、上位を章に昇格させる**(第2節) ── ここが構成の設計
3. **部品カタログ**(第3節)から必要な部品だけを選んで各章を組む
4. **商流の書き方**(第4節)だけは深さを妥協しない ── 会計論点はすべてここから導かれる
5. **納品前チェック**(第5節)を通す

---

## 0. 読者と到達水準

読者は会計士だが、**対象企業の業種の商習慣は知らない**。業界用語も商流の常識も共有していない。

到達水準は「読んだ翌日に経営者インタビューができる」こと。読者がレポートを閉じたあと、自分で質問を作れなければ失敗である。

記載はすべて **【事実】【推定】【要確認】** の確証区分で区別する。監査証拠ではなく、質問・PBC・リスク評価の仮説として提示する。

---

## 1. 不変の骨格(会社を問わず必ず置く5要素)

| #   | 要素                                                                   | なぜ会社を問わず必要か                             |
| --- | ---------------------------------------------------------------------- | -------------------------------------------------- |
| 1   | **表紙**:調査基準日・対象・目的・情報範囲・重要な前提 ＋ **本レポートの結論** | 読者が最初に必要とするのは、調査の射程と結論       |
| 2   | **エグゼクティブ・サマリー**(確証区分付きの発見事項)                   | 全体像と、事実／推定／要確認の切り分け             |
| 3   | **会社概要・経営体制**(事実に監査上の含意を併記)                       | 対象の同定と、以降の全論点の前提                   |
| 4   | **事業と商流**(業種を知らない読者に通じる水準まで)                     | 会計論点も不正リスクも、すべてここから導かれる     |
| 5   | **出典・調査限界・確証区分の凡例**                                     | 断定の抑制と、検証可能性の担保                     |

**これ以外の章はすべて選択**である。財務概況・棚卸資産・債権債務・不正・リスクマトリクス・PBC・監査アプローチなどは、対象会社でそれが重要な場合にのみ置く。

### 章のタイトルの付け方

一般名詞の章タイトル(「棚卸資産」「収益認識」)を使わない。**その会社で何が問題なのかを名指しする**タイトルにする。

- ✗ 「9. 棚卸資産」 → ○ 「総資産の49%を占める中古機械を、1台ずつどう評価するか」
- ✗ 「8. 収益認識」 → ○ 「『通関の都合で総額』は、基準の根拠になるか」
- ✗ 「12. 内部統制」 → ○ 「従業員12名で年商17億円を回す組織の職務分掌」

章番号は最終的な並び順で振り直す。骨格の5要素に固定番号を割り当てない。

## 2. 章立ての設計手順

### Step 1 ── 論点を洗い出す

商流・財務数値・開示原文・業界特性から、考えうる論点をすべて列挙する。この段階では絞らない。

### Step 2 ── 5つの物差しで順位づける

| 物差し             | 見るもの                                                       |
| ------------------ | -------------------------------------------------------------- |
| 金額的重要性       | 財務諸表項目の規模、当期純利益への感応度(「5%動けば利益の何%か」) |
| 見積りの不確実性   | 仮定の主観性、外部データで裏づけられるか                       |
| 不正リスクとの結合 | 動機・機会・正当化が揃うか。経営者が操作できる余地             |
| 情報の非対称性     | 外部から検証しにくいか。会社の説明に依存する度合い             |
| **会社固有性**     | **この会社・この商流でなければ生じない論点か**                 |

最後の物差しを最も重く見る。どの会社にも当てはまる一般論は、この報告書の価値ではない。

### Step 3 ── 上位3〜5論点を章に昇格させる

その論点だけで独立した章を立てる。章の中では、開示原文の引用 → 数値 → 図または表 → 監査上の対応、まで書き切る。

### Step 4 ── 残りを落とす先を決める

| 重要度       | 扱い                                             | 分量の目安     |
| ------------ | ------------------------------------------------ | -------------- |
| 最重要(3〜5) | 独立章。原文引用・数値・図・手続まで             | 全体の6割前後  |
| 重要         | 既存章の一節                                     | 各0.5〜1ページ |
| 通常         | 一覧表(リスクマトリクス等)の1行                  | 1行            |
| 該当なし     | **「該当なし」と明記する**(黙って省略しない)     | 1行            |

「該当なし」を明記するのは、検討した上で外したのか、検討漏れなのかを読者が区別できるようにするためである。書かない判断をした論点は「調査限界」に理由とともに残す。

### Step 5 ── 分量を配分する

最重要論点に本文の6割前後を割く。会社概要と沿革が最重要論点より長い報告書は、設計に失敗している。

### 参考:業種別の出発点(当てはめて終わりにしない)

思考の呼び水として使う。実際の論点は必ず対象会社の商流と数値から導き直す。

| 業種の型             | 最初に疑う論点                                                               |
| -------------------- | ---------------------------------------------------------------------------- |
| 在庫を持つ商社・卸   | 本人/代理人(総額・純額)、引渡しとカットオフ、棚卸資産の評価と滞留、与信       |
| SaaS・サブスク       | 履行義務の識別、一定期間にわたる認識、契約獲得コスト、解約・返金、契約負債   |
| 工事・受注制作       | 進捗度の見積り、原価総額の改訂、工事損失引当金、原価の付替え                 |
| 製造業               | 原価計算と配賦、標準原価差異の処理、棚卸資産の評価、固定資産の減損           |
| 不動産               | 棚卸不動産と固定資産の区分、収益認識時点、減損、共同事業のスキーム           |
| 人材・広告・代理店   | 本人/代理人、返金・キャンセル、変動対価、期ずれ                               |
| プラットフォーム     | 代理人判定、加盟店への支払と預り金、ポイント・クーポンの負債                 |
| 金融・リース         | 貸倒引当金の見積り、リース分類、金融商品の評価                               |
| 持株会社・グループ   | 関係会社株式の評価、関連当事者、グループ監査のスコーピング、経営指導料       |

対象会社がどの型にも当てはまらない場合、**それ自体が最重要の論点**である。なぜ既存の型に収まらないのかを商流の章で説明する。

## 3. 部品カタログ

必要な部品だけを選ぶ。すべてを使う必要はない。各部品の「規律」は、その部品を使うなら必ず守る。

### P1 メタ情報表(表紙)

| 項目       | 内容                                             |
| ---------- | ------------------------------------------------ |
| 調査基準日 | 【】                                             |
| 対象       | 【商号(証券コード／上場市場、非上場なら法人番号)】 |
| 目的       | 【】                                             |
| 情報範囲   | 【閲覧したもの】。【未閲覧のもの】               |
| 想定読者   | 【】                                             |
| 重要な前提 | 事実・推定・要確認を区分して記載                 |

**規律**:「未閲覧のもの」を必ず書く。閲覧範囲だけを書いた表は、読者に過信させる。

### P2 結論ボックス(表紙の直下)

> **本レポートの結論**
> 最重要の検討テーマは、①【】、②【】、③【】の3点である。

**規律**:3〜5点。各点に金額または比率を入れる。「収益認識に留意が必要」のような抽象語だけの結論を書かない。第2節Step 3で章に昇格させた論点と一致させる。

### P3 確証区分付きの発見事項

| 区分       | 発見事項                             |
| ---------- | ------------------------------------ |
| 【事実】   | 【数値と出典を伴う客観的事実】       |
| 【推定】   | 【導いた推定と、その根拠】           |
| 【要確認】 | 【会社に聞かなければ判断できない事項】 |

**規律**:推定には必ず「なぜそう推定したか」(金額の整合、業界慣行等)を添える。

### P4 事実＋監査上の含意の3列表

| 項目 | 公開情報で確認した内容 | 監査上の含意 |
| ---- | ---------------------- | ------------ |

**規律**:3列目を空欄にしない。含意が書けない事実は、載せる必要がない事実である。

### P5 時系列表(沿革・出来事)

| 年月 | 出来事 | 監査上の着眼 |
| ---- | ------ | ------------ |

### P6 財務数値の推移表

| 指標 | 第N期 | 第N+1期 | 第N+2期 | **読み方** |
| ---- | ----- | ------- | ------- | ---------- |

**規律**:「読み方」列を必ず持つ。数値を並べただけの表は読者に解釈を丸投げしている。比率は当方計算である旨を明記する。

### P7 「1件の取引で見る」ボックス ★商流理解の中核

> 【典型的な1件(例:【商材】1件・【金額】円)が動いたとする。】
> - **【パターンA】** → 売上高【】円／売上原価【】円／粗利【】円
> - **【パターンB】** → 売上高は【】円のみ
>
> 動いた現物も、担当者も、社内の呼び名も同じである。それでも損益計算書に載る金額は【】倍違う。分けているのは【判定軸】の一点だけである。

**規律**:必ず実額で書く。一般論で終わらせない。総額・純額の論点がない会社では、その事業で最も誤解されやすい会計上の分岐(一時点か一定期間か、資産計上か費用か、等)に置き換えて同じ形式で書く。

### P8 判定質問表

| #   | 質問 | Yesなら | Noなら | 確かめる資料 |
| --- | ---- | ------- | ------ | ------------ |

**規律**:判定の最小単位(1件／1個体／1契約)と、それを識別する一意のキーを明示する。

### P9 用語表

| 用語 | 業界外の人向けの意味 | なぜ会計・監査で問題になるか |
| ---- | -------------------- | ---------------------------- |

**規律**:2列目を専門用語で説明しない。この表にない業界用語を本文に登場させない。

### P10 商流図

```
【登場人物を左から右へ:【売り手】→【会社】→【買い手】
  ・商流のパターンごとに1行、右端に会計処理の違いを併記
  ・現物の流れと代金の流れを分けて描く
  ・各パターンに当期の金額を入れ、規模感が一目で分かるようにする】
```

**規律**:図は文章の要約として置かない。文章では伝わらない分岐・並行・順序を示すときだけ置く。図番号と図タイトルを付し、本文から参照する。

### P11 ステップ×会計の対応表

| ステップ | 実務で起きること | 会計上の出来事 | 証憑 |
| -------- | ---------------- | -------------- | ---- |
| 1 【】   | 【】             | 【仕訳なし】   | 【】 |

**規律**:仕訳が発生しないステップも「仕訳なし」と明記して並べる。どこで会計が動き、どこで動かないかが対比で分かる。

### P12 仕訳イメージ

```
【パターンA】 (借)【】 xxx / (貸)【】 xxx
【パターンB】 (借)【】 xxx / (貸)【】 xxx
```

**規律**:計上されない科目(例:棚卸資産を計上しない)と、代わりに生じうる経過勘定(預り金・立替金・仮受金)も書く。

### P13 会社の呼称と分類の対応表

| 会社が使う呼称 | 本レポートでの分類 | 対応が1対1でない理由 |
| -------------- | ------------------ | -------------------- |

**規律**:ずれがなければ「一致する」と明記する。ずれの有無自体が論点である。

### P14 よくある誤解表

| こう理解しがち | 実際は | なぜ間違えるか |
| -------------- | ------ | -------------- |

**規律**:3件以上。業種を知らない人が最初につまずく点を挙げる(例:同じ倉庫にあるから会社の在庫、会社が請求書を出しているから会社の売上)。

### P15 原文引用ボックス＋読み解き

> 「【会社の会計方針・注記の原文】」(出典:【資料名、注記名】)

この文言には、監査上見逃せない特徴が【N】つある。
1. 【特徴】 → 【会社に説明させるべきこと】

**規律**:要約せず原文を引く。会社の言葉と実際の処理・表示のずれは、原文を並べたときにしか見えない。

### P16 ブリッジ図

```
【上段に総額、下段に会計上の数値を置き、区分ごとに縦に落とす。
  途中で消える金額を明示する】
```

### P17 手続設計表

| 対象 | 検証すること | 証憑 |
| ---- | ------------ | ---- |

### P18 データ項目表

| データ項目 | 何が分かるか | これがないと検証できないこと |
| ---------- | ------------ | ---------------------------- |

**規律**:これが揃えば同一データセットから実施できる手続の範囲を述べ、初回PBCの最優先資料と位置づける。

### P19 分解の切り口表

| 切り口 | 見るポイント | 異常のサイン |
| ------ | ------------ | ------------ |

**規律**:平均値の裏に隠れるものを見つけるための部品。「回転期間63日」の裏の1年超滞留を見つける。

### P20 見積り一覧表＋感応度

| 項目 | 計上額 | 会社が示す主要な仮定 |
| ---- | ------ | -------------------- |

**規律**:金額の絶対値が小さくても、当期純利益に対する感応度が高ければそう書く(「5%計上すれば利益の20%相当」)。

### P21 不正シナリオ表

| シナリオ | 兆候 | 主な対応 |
| -------- | ---- | -------- |

**規律**:収益認識に係る不正リスクの推定(監基報240)と、経営者による内部統制の無効化リスクは、会社を問わず必ず含める。他のシナリオは商流から導く。

### P22 リスク評価マトリクス

| 領域 | 固有リスク | 主要アサーション | 優先度 | 計画上のレスポンス |
| ---- | ---------- | ---------------- | ------ | ------------------ |

**規律**:優先度は第2節Step 2の順位づけと一致させる。マトリクスで「最重要」とした領域が独立章になっていなければ、どちらかが間違っている。

### P23 インタビュー質問集

| テーマ | 質問 |
| ------ | ---- |

**規律**:一般的な質問を並べない。本文で【要確認】とした事項が、ここに質問として現れているか対応を取る。

### P24 PBCリスト

| No. | 区分 | 依頼資料 |
| --- | ---- | -------- |

**規律**:本文で「分解させる」「突合する」と書いた手続に必要な資料が、漏れなく載っているか対応を取る。

### P25 監査アプローチ(フェーズ)

理解・データ確保 → 統制評価 → 実証手続 → 連携。**規律**:フェーズ3の手続が、章に昇格させた最重要論点をすべてカバーしているか確認する。

### P26 KAM候補表

| 候補 | なぜ特に重要と考えられるか | 監査上の対応の概要 |
| ---- | -------------------------- | ------------------ |

**規律**:制度上の記載要否とは別に、調書上厚く文書化すべき領域として示す。

### P27 注意喚起ボックス

> **【「〜だけで決めない」「〜で足りるか」形式の見出し】**
> 【読者が陥りやすい早合点を名指しし、正しい判断軸を示す】

**規律**:会社の説明を引用したうえで、どこに検討の余地があるかを述べる。会社の説明を否定するのではなく、根拠として十分かを問う形にする。

### P28 出典・調査限界・確証区分

主要一次資料(発行者・資料名・日付・URL・参照日) / 補助資料 / 適用基準 / 調査限界 / 確証区分の凡例。

**規律**:調査限界には、①開示されていない内訳と推定の根拠、②現況が未確認の事項、③検討したが章にしなかった論点とその理由、を書く。

## 4. 商流の書き方(ここだけは深さを妥協しない)

商流は不変の骨格である。会計論点も不正リスクも、すべてここから導かれる。論点の絞り込みで削ってよい章ではない。

### 商流の章に必ず含める要素

1. **この事業を一言でいうと** ── 専門用語ゼロで3〜5文。誰から何を得て、誰に何を渡し、どこで儲けるか
2. **1件の取引で見る**(P7) ── 実額で
3. **判定質問**(P8)と**会社の呼称との対応**(P13)
4. **用語表**(P9)
5. **商流図**(P10)
6. 商流ごとに:**一言でいうと／登場人物／取引の流れ／ステップ×会計の対応表(P11)／仕訳イメージ(P12)／監査の着眼**
7. 商流ごとに:**この商流の分岐点**と**初心者が誤りやすい点**を各1文
8. **よくある誤解**(P14)

### 平易化の規律

- 業界用語は初出時に日常語で言い換える。言い換えきれない語は用語表に入れ、以降はその表の語だけで書く。「業界では常識だから」を理由に省略しない。
- 主語と目的語を省かない。「販売する」ではなく「会社が、買い手に、自社が所有する◯◯を販売する」。
- 抽象論より先に、1件の取引を金額入りで追う。
- 「初心者が誤りやすい点」は「◯◯の時点でも、△△の時点でもない」の形で書く。
- 会社の呼称をそのまま分類名にしない。判定軸で分類し直す。

## 5. 納品前チェック

### 構成

- [ ] 結論ボックスの3〜5点と、独立章に昇格させた論点が一致しているか
- [ ] リスクマトリクスで「最重要」とした領域が、独立章になっているか
- [ ] 最重要論点に本文の6割前後を割いているか。会社概要が最重要論点より長くないか
- [ ] 一般名詞の章タイトル(「棚卸資産」等)が残っていないか
- [ ] 検討したが章にしなかった論点を、調査限界に理由とともに残したか

### 内容

- [ ] すべての表・主張に出典行があるか。当方計算を明記したか
- [ ] 【事実】【推定】【要確認】が区別され、推定に根拠が添えてあるか

### 平易性(商流の章)

対象業種を知らない読者になったつもりで読み、次に答えられるか。答えられない箇所が平易化の失敗箇所である。

- [ ] この会社は誰から何を得て、誰に何を渡し、どこで儲けているか
- [ ] 各商流で、その現物は誰のものか。会社のものになるのはいつか
- [ ] 会社の呼称と会計上の分類は一致しているか。ずれているならどこか
- [ ] 用語表にない業界用語が本文に残っていないか
- [ ] 主語のない文(「販売する」「計上される」)が残っていないか
- [ ] 商流の説明だけを読んで、経営者への質問を自分で作れるか
